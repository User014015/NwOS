# Why not 2.x Version?

We decided that the 1.x version is better than the 2.x version; the latter has too few features and is inconvenient for programming, unlike the first version. In the first version, we were able to transition to 64-bit mode and implement an improved file system, whereas doing all of this in the second version proved far too difficult.

You can check the differences between the 1.x and 2.x versions, they are significant, and the 2.x version took a long time to develop.

# 1.x Version changes
