# NwC — подробный гайд

Это руководство по **текущей рабочей версии NwC 1.x** — тому компилятору, который лежит в `compiler/` и запускает `.nwo`-файлы в NwOS.

> Версия 2.0 пока сырая, поэтому здесь описано только то, что реально работает сейчас.

---

## 1. Что такое NwC

NwC — простой встроенный язык программирования для NwOS.

- Исходник: `.nw`
- Скомпилированная программа: `.nwo`
- Компилятор: `compiler/builded/nwc` (его собирает `compiler/build.sh`)
- Запуск в NwOS: `run имя_файла.nwo`

NwC специально сделан похожим на C, но проще. Например, вместо `int` используется `1A`.

---

## 2. Быстрый старт

### 2.1. Собрать компилятор

Из корня проекта:

```bash
bash compiler/build.sh
```

После сборки появится:

```text
compiler/builded/nwc
```

### 2.2. Написать программу

Создай файл, например `NwDev/hello.nw`:

```c
#include <nwc.h>

1A main() {
    nw::out << "Hello from NwC!" << nw::endl;
    return 0;
}
```
### 2.3. Скомпилировать

```bash
compiler/builded/nwc NwDev/hello.nw -o NwDev/hello.nwo
```

Или через готовый скрипт:

```bash
bash NwDev/buildCompiler.sh hello.nw
```

### 2.4. Запустить

В NwOS:

```text
run hello.nwo
```

Файл `.nwo` должен лежать в файловой системе NwOS. Как добавить его в образ — см. раздел 13.

## 3. Структура программы

Минимальная программа:

```c
#include <nwc.h>

1A main() {
    return 0;
}
```

Правила:

- `#include <nwc.h>` — традиционная строка. Сейчас компилятор её принимает и игнорирует, но писать её желательно всегда.
- Точка входа — функция `main`.
- Тело функции обязательно в `{ ... }`.
- В конце `main` желательно `return 0;`.
- Комментарии (`//` и `/* */`) **пока не поддерживаются**.

`main` можно объявить и как `0A` (аналог `void`):

```c
0A main() {
    return;
}
```

Но основной рабочий вариант — `1A main()`.

Если написать `int` или `void`, компилятор подскажет замену:

```text
Int is not supported by NwC, Do you mean '1A'?
Void is not supported by NwC, Do you mean '0A'?
```

## 4. Типы данных

| Тип NwC | Что означает | Пример |
|---|---|---|
| `1A` | целое число (int) | `1A x = 10;` |
| `0A` | «пусто» / void, для `main` и функций без результата | `0A main() { return; }` |
| `lng` | длинное целое | `lng x = 100000;` |
| `flt` | число с дробной частью | `flt x = 1.5;` |
| `bol` | логическое значение | `bol b = true;` |
| `char` | один символ | `char c = 'A';` |
| `str` | строка | `str s = "hello";` |
| `char name[N]` | массив символов / строка | `char cmd[32];` |
| `const 1A` | модификатор const | `const 1A x = 10;` |
| `nonzero 1A` | модификатор unsigned | `nonzero 1A x = 10;` |
| `needed 1A` | модификатор volatile | `needed 1A x = 10;` |
| `lng lng` | 64-битное целое | `lng lng x = 123456789;` |

Модификаторы `const`, `nonzero` и `needed` пока принимаются парсером, но их проверка/влияние на VM ещё не реализованы. `lng lng` уже работает как длинное целое.

Важные ограничения:

- Реально в VM все числа хранятся как целые. `flt` парсится, но при выводе и арифметике дробная часть отбрасывается.
- `bol` выводится как `true` или `false`.
- `char` выводится как символ.
- `str` и `char[]` выводятся как строки.
- Размер `char name[N]` сейчас **не ограничивает** ввод. VM хранит до 255 символов.
- Индексация массивов (`arr[0]`) пока не поддерживается. `char name[32]` используется как строковая переменная.

## 5. Переменные

Объявление без значения:

```c
1A x;
str name;
char cmd[32];
```

Объявление с начальным значением:

```c
1A x = 42;
bol ok = true;
flt pi = 3.14;
str hello = "hi";
char letter = 'A';
```

### Присваивание после объявления

Присваивание работает:

```c
1A x = 1;
x = 2;
x = x + 10;
```

Присваивать можно переменным внутри функций. Для `const` проверка пока не включена.

### Имена переменных

Нельзя использовать зарезервированные слова как имена. Например, `line` — это ключевое слово, поэтому переменную нельзя назвать `line`.

Зарезервированные слова:

```text
return true false if else while for break continue call sleep
rect flt bol lng char str nw out endl cin line
low out8 in8 out16 in16 memory_write8 memory_read8
cli sti time color getkey clear
__asm__ nonzero const needed
```

Ограничения VM:

- максимум 32 переменных;
- имя переменной — до 31 символа.

## 6. Вывод: `nw::out`

Вывод работает через `nw::out` и `<<`:

```c
nw::out << "Hello" << nw::endl;
```

Можно выводить несколько значений подряд:

```c
1A age = 12;
nw::out << "age = " << age << nw::endl;
```

Перевод строки — `nw::endl`:

```c
nw::out << "line 1" << nw::endl;
nw::out << "line 2" << nw::endl;
```

Что выводится:

| Значение | Вывод |
|---|---|
| `1A`, `lng` | число |
| `flt` | только целая часть |
| `bol` | `true` / `false` |
| `char` | символ |
| `str`, `char[]` | строка |

Пробелы автоматически не добавляются:

```c
nw::out << "x=" << 5 << nw::endl;  // x=5
```

### Escape-последовательности

В строках и символах теперь работают:

| Запись | Значение |
|---|---|
| `\n` | перевод строки |
| `\r` | возврат каретки |
| `\t` | табуляция |
| `\\` | обратный слэш |
| `\"` | двойная кавычка |
| `\'` | одинарная кавычка |

Пример:

```c
nw::out << "line 1\nline 2\n";
nw::out << "tab:\there" << nw::endl;
nw::out << "quote: \"NwC\"" << nw::endl;
```

`nw::endl` тоже работает и делает то же, что `\n` в конце вывода.

### Цветной вывод

Полная форма:

```c
nw::out!COLOR << "hello " << name << nw::endl!COLOR:RED;
```

Это выведет строку красным цветом и переведёт строку.

Версия без перевода строки:

```c
nw::out!COLOR << "hello " << name << no_endl!COLOR:GREEN;
nw::out << " <- продолжение" << nw::endl;
```

Доступные цвета:

```text
BLACK, BLUE, GREEN, CYAN, RED, MAGENTA, BROWN,
LIGHT_GRAY, DARK_GRAY, LIGHT_BLUE, LIGHT_GREEN,
LIGHT_CYAN, LIGHT_RED, LIGHT_MAGENTA, YELLOW, WHITE
```

Цвет ставится на всё выражение и после него восстанавливается предыдущий.
Имя `LIGHT_GRAY` можно писать и как `LIGHT_GREY` или `GRAY`.

## 7. Ввод

### 7.1. Ввод в строку или `char[]`

```c
char cmd[32];
nw::cin >> cmd;
```

Вся введённая строка попадёт в `cmd`.

То же самое со `str`:

```c
str name;
nw::cin >> name;
```

### 7.2. Ввод числа

```c
1A number;
nw::cin >> number;
```

Введённая строка разбирается как целое число. Поддерживается минус:

```text
-42
```

### 7.3. Ввод целой строки через `nw::line`

```c
char text[64];
nw::line(nw::cin, text);
```

Сейчас `nw::line` фактически делает то же самое, что и `nw::cin >> text`.

### Важно

- `nw::cin` не печатает приглашение `>`. Его нужно выводить самому:
  ```c
  nw::out << "> ";
  nw::cin >> cmd;
  ```
- Если ввести буквы в числовую переменную, получится `0` (или число до первого нецифрового символа).

## 8. Операторы и выражения

Поддерживаются:

| Оператор | Значение |
|---|---|
| `+` | сложение |
| `-` | вычитание |
| `*` | умножение |
| `/` | деление |
| `==` | равно |
| `!=` | не равно |
| `<` | меньше |
| `>` | больше |
| `<=` | меньше или равно |
| `>=` | больше или равно |

Скобки работают:

```c
nw::out << (2 + 3) * 4 << nw::endl;
```

Числа можно писать в десятичном и шестнадцатеричном виде:

```c
nw::out << 255 << " " << 0xFF << nw::endl;  // 255 255
```

Это удобно для цветов `nw::rect`, например `0xFF0000` — красный.

### Нет приоритета операторов

Очень важная особенность: **все операторы выполняются слева направо**, без привычного приоритета.

```c
nw::out << 2 + 3 * 2 << nw::endl;
```

Выведет `10`, потому что это `(2 + 3) * 2`, а не `2 + (3 * 2)`.

Если нужен обычный порядок — ставь скобки:

```c
nw::out << 2 + (3 * 2) << nw::endl;  // 8
```

### Что ещё пока не поддерживается

- унарный минус (`-5`) — пиши `0 - 5`;
- `%` (остаток от деления);
- `&&`, `||`, `!`;
- битовые операции;
- инкремент/декремент.

## 9. Условия: `if` / `else`

```c
if (condition) {
    // да
} else {
    // нет
}
```

Пример:

```c
1A x;
nw::cin >> x;

if (x > 10) {
    nw::out << "big" << nw::endl;
} else {
    nw::out << "small" << nw::endl;
}
```

`else if` тоже работает:

```c
if (x > 10) {
    nw::out << "big" << nw::endl;
} else if (x > 5) {
    nw::out << "medium" << nw::endl;
} else {
    nw::out << "small" << nw::endl;
}
```

Любое ненулевое число считается истиной:

```c
if (1) { /* выполнится */ }
if (0) { /* не выполнится */ }
```

## 10. Циклы: `while`

```c
while (condition) {
    // тело цикла
}
```

Пример:

```c
1A i = 0;
while (i < 5) {
    nw::out << i << nw::endl;
    i = i + 1;
}
```

Для команд часто удобен бесконечный цикл и `break`:

```c
while (1) {
    char cmd[32];
    nw::cin >> cmd;

    if (strcmp(cmd, "exit") == 0) {
        break;
    }
}
```

### `break`

Выход из цикла:

```c
while (1) {
    if (strcmp(cmd, "exit") == 0) {
        break;
    }
}
```

### `continue`

Переход к следующей проверке условия цикла:

```c
while (1) {
    if (strcmp(cmd, "skip") == 0) {
        continue;
    }
}
```

`for` пока не поддерживается, хотя слово и распознаётся лексером.

## 11. `strcmp` — сравнение строк

В NwC есть встроенная функция `strcmp`:

```c
strcmp(a, b)
```

Она возвращает:

- `0`, если строки равны;
- отрицательное число, если `a` меньше `b`;
- положительное число, если `a` больше `b`.

Обычно используется так:

```c
if (strcmp(cmd, "help") == 0) {
    nw::out << "commands: help, exit" << nw::endl;
}
```

`strcmp` работает со `str`, `char[]` и строковыми литералами:

```c
char cmd[32];
nw::cin >> cmd;

if (strcmp(cmd, "help") == 0) {
    nw::out << "help" << nw::endl;
} else if (strcmp(cmd, "exit") == 0) {
    return 0;
} else {
    nw::out << "unknown: " << cmd << nw::endl;
}
```

### `strncmp` — сравнение первых N символов

```c
strncmp(a, b, n)
```

Сравнивает не больше `n` символов. Возвращает `0`, если первые `n` символов совпадают.

```c
if (strncmp(cmd, "echo", 4) == 0) {
    nw::out << "это команда echo" << nw::endl;
}
```

Полезно для команд с аргументами и проверки начала строки.

## 12. Пользовательские функции

Функции объявляются на верхнем уровне. Тип возврата — `1A` или `0A`:

```c
1A add(1A a, 1A b) {
    return a + b;
}

0A hello(char s[5]) {
    nw::out << "hi " << s << nw::endl;
}
```

Вызов-инструкция пишется через `call`:

```c
call hello("Bob");
```

Функцию, которая возвращает значение, можно использовать в выражении:

```c
1A x = add(2, 3);
nw::out << "sum=" << x << nw::endl;
```

Полный пример:

```c
1A add(1A a, 1A b) {
    return a + b;
}

0A hello(char s[5]) {
    nw::out << "hi " << s << nw::endl;
}

0A main() {
    call hello("Bob");
    nw::out << add(2, 3) << nw::endl;
    return;
}
```

Что уже работает:

- до 16 параметров;
- параметры и локальные переменные имеют область видимости вызова;
- вложенные вызовы и рекурсия;
- функции можно объявлять до или после `main`;
- `return` возвращает целое значение;
- `call f();` для вызова без использования результата.

Ограничение: возвращать строки из функций пока нельзя — `return` оставляет только целое.

## 13. `__asm__` и клавиши

### `__asm__("hlt")`

Разрешённый низкоуровневый вызов:

```c
#include <asm.h>

1A main() {
    while (1) {
        __asm__("hlt");
    }
}
```

Сейчас поддерживается только инструкция `hlt` — остановка CPU до следующего прерывания. Для других инструкций компилятор выдаст `unsupported asm instruction`.

### Имена клавиш

Вместо числовых кодов можно писать имена:

```c
1A key;
key = nw::getkey(ESC);
nw::out << "KEY=" << key << nw::endl;
```

- `nw::getkey()` — прочитать следующую клавишу;
- `nw::getkey(KEY)` — ждать конкретную клавишу и вернуть её код.

Доступные имена: `NONE`, `ESC`, `ENTER`, `BACKSPACE`, `TAB`, `UP`, `DOWN`,
`LEFT`, `RIGHT`, `SUPER_S`, `SPACE`. Есть алиасы с префиксом `KEY_`, например
`KEY_ESC`.

Коды соответствуют драйверу клавиатуры NwOS: `ESC` = 255, `ENTER` = 256,
`UP` = 259, `SPACE` = 32.

## 14. Встроенные функции `nw::`

| Функция | Статус | Описание |
|---|---|---|
| `nw::out << ... << nw::endl;` | работает | вывод |
| `nw::cin >> var;` | работает | ввод строки или числа |
| `nw::line(nw::cin, var);` | работает | ввод строки |
| `strcmp(a, b)` | работает | сравнение строк |
| `strncmp(a, b, n)` | работает | сравнение первых `n` символов |
| `nw::clear();` | работает | очистка экрана |
| `nw::color(n);` | работает | цвет текста |
| `nw::out!COLOR ... endl!COLOR:NAME;` | работает | цветной вывод |
| `nw::time();` | работает | выводит текущее время `ЧЧ:ММ:СС` |
| `nw::rect(x, y, w, h, color);` | работает | рисует заполненный прямоугольник |
| `nw::draw!FRAME << ...;` | работает | окно Win95 с заголовком и кнопкой закрытия |
| `nw::draw!FRAME ... frame::no::window` | работает | рамка без заголовка (меню, панели) |
| `nw::draw!TEXT << ... << "text";` | работает | текст в пиксельных координатах |
| `nw::draw!CUBE << ...;` | работает | куб с размером по умолчанию |
| `clear_screen();` | работает | очистка всего экрана |
| `sleep(ms);` | работает | пауза в миллисекундах |
| `nw::getkey()` / `nw::getkey(KEY)` | работает | читает клавишу; с аргументом ждёт конкретную клавишу |

Низкоуровневые команды (`low`, `out8`, `in8`, `out16`, `in16`, `memory_write8`, `memory_read8`, `cli`, `sti`) пока только распознаются лексером, но не поддерживаются парсером.

### Цвет текста

```c
nw::color(3);
nw::out << "colored text" << nw::endl;
```

Цвета задаются числами, как в обычной текстовой консоли: `0` — чёрный, `4` — красный, `15` — белый.
Для цветного вывода с автоматическим восстановлением цвета используй `nw::out!COLOR`.

### Время

```c
nw::time();
```

Выведет, например:

```text
14:35:09
```

### Пауза

```c
sleep(1000);   // подождать примерно секунду
```

Аргумент — миллисекунды.

### Клавиша

`nw::getkey()` возвращает код нажатой клавиши, поэтому его можно вывести или сохранить:

```c
1A key = nw::getkey();
nw::out << "KEY=" << key << nw::endl;
```

### Прямоугольники

```c
nw::rect(x, y, width, height, color);
```

Аргументы: левый верхний угол `(x, y)`, размеры `width` и `height`, цвет в формате `0xRRGGBB`.

```c
nw::rect(10, 20, 100, 50, 0x00FF00);  // зелёный прямоугольник
nw::rect(0, 0, 640, 400, 0x000080);   // тёмно-синий фон
```

После начала рисования текст выводится поверх графики и больше не стирает нарисованное. `nw::clear();` возвращает обычный текстовый режим.

### Новый синтаксис `nw::draw!`

Окно в стиле Windows 95:

```c
nw::draw!FRAME << x=100,x2=500; \
                  y=80,y2=300; \
                  TITLE="My Window"; \
                  !COLOR=NAVY;
```

`x/x2` и `y/y2` задают границы. По умолчанию рисуются серая поверхность,
синий заголовок, `TITLE` и кнопка закрытия. Цвет `COLOR` задаёт цвет заголовка.

Рамка без заголовка — для меню, панелей и кнопок:

```c
nw::draw!FRAME << x=8,x2=228; \
                  y=425,y2=691; \
                  frame::no::window; \
                  !COLOR=BLACK;
```

Кнопка закрытия пока декоративная: мыши нет, выход из GUI — клавиша `ESC`.

Текст в пиксельных координатах:

```c
nw::draw!TEXT << x=20,y=30 !COLOR=WHITE << "Hello, NwOS!";
```

Куб с размером по умолчанию:

```c
nw::draw!CUBE << auto::func::connect << COLOR=BLUE;
```

Цвета для `draw`: `BLACK`, `WHITE`, `RED`, `DARK_RED`, `LIGHT_RED`,
`GREEN`, `DARK_GREEN`, `LIGHT_GREEN`, `BLUE`, `DARK_BLUE`, `LIGHT_BLUE`,
`CYAN`, `MAGENTA`, `YELLOW`, `BROWN`, `ORANGE`, `PURPLE`, `PINK`,
`GRAY`, `LIGHT_GRAY`, `DARK_GRAY` и другие. Можно передать и `0xRRGGBB`.

Текущий framebuffer — 1280×720, поэтому координаты больше 1279/719 обрезаются.
При первом графическом примитиве экран очищается от текста консоли.

Старые `nw::rect` и `nw::out` оставлены для совместимости.

### Очистка экрана

```c
clear_screen();
```

`nw::clear();` делает то же самое и возвращает текстовый режим.

## 15. Как собрать и запустить свою программу

### Вариант A. Через `NwDev`

```bash
bash compiler/build.sh
bash NwDev/buildCompiler.sh shell.nw
```

Результат: `NwDev/shell.nwo`.

```bash
compiler/builded/nwc NwDev/shell.nw -o NwDev/shell.nwo

### Добавить программу в образ NwOS

Есть два способа.

#### Способ 1. Через встроенную rootfs

Положить `.nwo` в `sys/rootfs/bin/`, перегенерировать rootfs и собрать ISO:

```bash
cp NwDev/shell.nwo sys/rootfs/bin/shell.nwo
python3 tools/gen_rootfs.py
bash build.sh
```

После загрузки:

```text
run shell.nwo
```

#### Способ 2. Через `nwimg`

Если используешь `img/disk.img`:

```bash
./nwimg add img/disk.img NwDev/shell.nwo shell.nwo
```

Посмотреть файлы в образе:

```bash
./nwimg list img/disk.img
```

### Ограничение размера `.nwo`

Файловая система хранит файл в **32 секторах — до 16384 байт**. Заголовок `.nwo` занимает 20 байт, поэтому код и данные вместе могут занимать примерно **16364 байта**.

Загрузчик `.nwo` и файловая система рассчитаны на файлы до **16384 байт**. Этого достаточно для GUI вроде `NwDev/gui.nwo` (около 12 КБ).

Если пересоздаёшь `img/disk.img`, отформатируй его новой версией NwOS: старая раскладка с одним сектором на файл несовместима.

## 16. Полный пример: простая оболочка

Файл `NwDev/shell.nw`:

```c
#include <nwc.h>

1A main() {
    char cmd[32];
    nw::out << "NwC shell. Type help." << nw::endl;

    while (1) {
        nw::out << "> ";
        nw::cin >> cmd;

        if (strcmp(cmd, "help") == 0) {
            nw::out << "help, clear, echo, exit" << nw::endl;
        } else if (strcmp(cmd, "clear") == 0) {
            nw::clear();
        } else if (strcmp(cmd, "echo") == 0) {
            nw::out << "Echo> ";
            char echo[32];
            nw::line(nw::cin, echo);
            nw::out << echo << nw::endl;
        } else if (strcmp(cmd, "exit") == 0) {
            return 0;
        } else {
            nw::out << "unknown: " << cmd << nw::endl;
        }
    }

    return 0;
}
```

Компиляция:

```bash
compiler/builded/nwc NwDev/shell.nw -o NwDev/shell.nwo
```

Запуск в NwOS:

```text
run shell.nwo
```

## 17. Частые ошибки

### `expected include or function`

Верхний уровень программы может содержать только `#include` и объявления функций. Весь исполняемый код должен быть внутри `main`.

### `expected variable name`

Скорее всего, имя переменной совпадает с ключевым словом. Например, нельзя:

```c
char line[32];   // line — ключевое слово
```

Используй:

```c
char buf[32];
```

### `int` и `void` не поддерживаются

Компилятор специально подсказывает замену:

```text
Int is not supported by NwC, Do you mean '1A'?
Void is not supported by NwC, Do you mean '0A'?
```

Пиши:

```c
1A main() {
    return 0;
}
```

или:

```c
0A main() {
    return;
}
```

### `unsupported asm instruction`

Сейчас поддерживается только:

```c
__asm__("hlt");
```

### Программа выводит мусор в конце строки

Это было исправлено в VM: строки теперь печатаются по длине из `.nwo`. Пересобери ядро/ISO:

```bash
bash build.sh
```

### Цветной вывод не компилируется

Проверь, что есть и начало, и конец:

```c
nw::out!COLOR << "text" << nw::endl!COLOR:RED;
```

Для вывода без новой строки:

```c
nw::out!COLOR << "text" << no_endl!COLOR:RED;
```

### `Unknown function` / `Wrong argument count`

VM не нашла функцию с таким именем или ей передали не то число аргументов:

```c
call hello("Bob");   // функция hello должна существовать
```

Проверь имя и количество аргументов в объявлении функции.

## 18. Что пока не работает (кратко)

- комментарии;
- `int`, `void`, `for`;
- `%`, `&&`, `||`, `!`, битовые операции;
- унарный минус;
- индексация массивов;
- возврат строк из функций;
- динамическое переключение разрешения и мышь;
- `nw::gfx` (используй `nw::draw!`).
