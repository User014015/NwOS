Type commands into the NwOS shell. Arguments in <angle brackets> are required; [square brackets] are optional.

Essentials

The first commands to know when you land in the shell.

  • help start here

    Show the list of built-in commands.

  • about

    Show information about NwOS and this build.

  • nwfetch

    Display a compact system summary.

  • clear

    Clear the terminal screen.

  • settings

    Show the current settings stored in sys.conf.

  • mem

    Show memory usage and availability.

  • time

    Show the current time and date.

  • zones

    List the available time zones.

  • uptime

    Show how long the system has been running.

Files

Browse, create, and edit files on the active disk.

  • ls

    List files and directories in the current directory.

  • cd <dir>

    Change directory. Use .. to move one level up.

  • mkdir <dir>

    Create a new directory.

  • create <file>

    Create an empty file.

  • read <file>

    Print the contents of a text file.

  • write <file> <text>

    Write text to a file.

  • edit <file>

    Open a file in the built-in text editor.

  • delete <file>

    Delete a file.

  • rm [-r] <file> careful

    Remove a file. Use -r to remove a directory.

  • rmdir <dir> careful

    Remove a directory together with its contents.

Storage

Inspect disks, switch drives, and install NwOS.

  • format erases data

    Erase all files on the current disk and reinstall the root filesystem.

  • disk <D>

    Show detailed size and filesystem information for one disk.

  • drive <C|D|n>

    Switch the active disk by letter or number.

  • disks

    List all ATA disks detected by the system.

  • install erases data

    Run the installation wizard and write NwOS to a disk.

  • hexview <file>

    Display a file as a hexadecimal byte map.

  • nwocheck <file>

    Inspect an NWO executable and its opcodes.

Programs & graphics

Run NWO programs and launch the graphical shell.

  • run <file.nwo>

    Run an NWO executable from the current directory.

  • apps

    List the applications installed on the system.

  • games

    Open the games menu.

  • calc

    Launch the calculator.

  • gui graphics

    Launch the graphical shell written in NwC.

System

Change the shell, inspect hardware, and control the machine.

  • color

    Change the shell color settings.

  • change color

    Change the prompt color.

  • change invite

    Change the shell prompt text.

  • timezone <num>

    Set the active time zone.

  • date

    Set a custom date.

  • cpu

    Show information about the processor.

  • lspci

    List PCI devices detected by the system.

  • reboot

    Restart the computer.

Network

Check the network stack and reach other hosts.

  • net

    Show network status: MAC address, IP address, and link state.

  • ping <host|ip>

    Ping a host name or IP address.

Extras

Small utilities and a few fun commands.

  • echo <text>

    Print text back to the terminal.

  • generate num

    Generate a random number.

  • random word

    Generate a random word.

  • chat

    Talk to the built-in chat companion.

  • more

    Show additional commands that are not in the short list.
