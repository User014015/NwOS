About the project

NwOS is a small hobby operating system built completely from scratch. It has its own bootloader written in NASM, a C kernel, a simple on-disk filesystem, a text-mode shell with a scrollback buffer, and a compiler (NwC) with its own lexer and parser.

The goal of the project is to learn how a real operating system is put together — from the very first instruction the CPU executes at boot, all the way up to a running shell and user programs.

Features

  • Custom bootloader (NASM, real mode → protected mode)
  • 32-bit C kernel running in ring 0
  • VGA text-mode console with 300-line scrollback
  • PS/2 keyboard driver
  • ATA disk driver and simple filesystem
  • Built-in games and calculator
  • NwC — a compiler for the NwLang language
